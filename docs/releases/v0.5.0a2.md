# R48Display v0.5.0a2 — alpha (arduino-esp32 3.x)

**Pre-release for hardware testing.** This is the first build on the new
**arduino-esp32 3.x / ESP-IDF 5.x** framework — a large under-the-hood change.
Please install it over **USB** and put it through its paces before it becomes a
stable 0.5.0.

## Install over USB — not OTA
The 3.x framework ships a new **bootloader**, and an over-the-air *app* update
does not replace the bootloader. Flash this build from the USB installer so the
bootloader, partition table, and app all move together:

**https://picklepc.github.io/R48Display/** → choose **v0.5.0a2** in the Version
dropdown → **Install**. Your saved settings (Wi-Fi, BMS, hours, pay) are kept —
the installer doesn't touch the storage partition.

(Once a 3.x build is on the device, later 3.x → 3.x updates can go OTA again.)

## What changed
- **Framework migrated to arduino-esp32 3.x (ESP-IDF 5.x).** Same features and
  UI as v0.4.10 — the goal is 3.x's better memory management and the ability to
  size the TLS buffers to fit this device.
- 3.x build fixes: display driver bumped to **GFX 1.6.6**; the loop watchdog now
  uses the 3.x `esp_task_wdt_config_t` API; OTA auto-rollback and the battery ADC
  were verified against the 3.x core.
- Carries all of **v0.4.9 + v0.4.10**'s web-stability work (streamed JSON,
  hidden-tab poll pause, and the reclaimed update-checker memory).

## Still to come before stable 0.5.0
- **On-device update checks stay disabled in this alpha** (as in v0.4.10). The
  TLS-buffer sizing that makes them work on 3.x is the next step — for now,
  "Check for updates" still points you to the USB installer.

## Please test and report
- **Mowing detection** — mic + current still flags "mowing" on the dashboard and
  the LVGL screen (this used the legacy I2S driver, now deprecated on 3.x).
- **BLE / BMS** — connects and reconnects; battery %, current, and temps read
  correctly.
- **Display, touch, weather, MQTT** — behave as they did on v0.4.10.
- **Web dashboard stays responsive** over a long session with a tab left open —
  this is the stability target, now on 3.x's allocator.
- **A watchdog reboot** (if any) recovers cleanly and doesn't roll back.
