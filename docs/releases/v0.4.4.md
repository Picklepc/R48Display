# R48Display v0.4.4

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Fix: freezes/network death after a failed update check
- The v0.4.1 "free Bluetooth and retry" fallback could tear the Bluetooth stack down **while the main loop was inside a Bluetooth call** — a race that corrupted the radio/network stack. Depending on timing it killed Wi-Fi while the screen kept running, or froze the whole unit. It typically fired ~25 s after boot (when the background update check failed), which made it look like the Maintenance page was the cause.
- The teardown now handshakes with the main loop and waits until Bluetooth is idle before proceeding.
- The Bluetooth-teardown retry now runs **only for manual checks** (the button) — a background check will never interrupt Bluetooth, hour counting, or pay tracking mid-mow.

## Watchdog: no more freeze-until-power-cycle
- A 30-second loop watchdog now reboots the device automatically if the main loop ever hard-blocks, instead of freezing until someone pulls power. Combined with OTA rollback protection, a watchdog reboot is always safe.
