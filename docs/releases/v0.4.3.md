# R48Display v0.4.3

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Update check: likely fix + real diagnostics
- **Fixed:** the update check sent its request headers incorrectly — they were set before the connection was opened and could be dropped, and GitHub's API rejects requests without a `User-Agent`. This alone could cause every check to fail with "Could not reach GitHub" regardless of connectivity.
- **Diagnostics:** if a check still fails, the error now names the exact failing stage instead of a generic message — `Wi-Fi not connected`, `DNS lookup failed`, `TCP to <ip>:443 failed`, `TLS handshake failed (free heap N)`, or `GitHub HTTP <code>` — shown right on the Firmware Update card. The retry-without-Bluetooth fallback from v0.4.1 is retained and reports separately.
- Added connect/handshake timeouts so a dead network fails fast instead of hanging the check.
