# R48Display v0.5.0a3 — alpha (setup AP recovery)

**Pre-release for hardware testing.** Install over **USB** from the web
installer, same as v0.5.0a2. If the installer asks about erasing, leave
**Erase device** unchecked unless you intentionally want a factory reset.

## Installer data preservation
- Fixes the web installer manifest so ESP Web Tools prompts before erasing a
  device it cannot identify as already running R48Display.
- The safe/default prompt path leaves `Erase device` unchecked and preserves
  saved settings, BMS setup, hours, pay records, and maintenance data in NVS.
- This corrects the v0.5.0a2 installer behavior where a fresh install path could
  erase user data without giving the intended choice.

## Setup AP / captive portal
- Adds captive DNS while the setup AP is active, so phones and laptops should
  open the temporary setup page like a sign-in portal.
- Unknown captive-check URLs now redirect to `http://192.168.4.1/` while the AP
  is active.
- If saved Wi-Fi credentials exist but STA cannot connect for about 90 seconds,
  the device falls back to the setup AP instead of staying unreachable.
- Setup AP reliability is improved by disabling Wi-Fi sleep in AP mode and
  allowing up to four AP clients.
- Saving settings from AP mode now retries STA even when the SSID is unchanged,
  which fixes the "same network, corrected password" case.

## Still alpha
- This is still the arduino-esp32 3.x / ESP-IDF 5.x migration test build.
- On-device update checks remain disabled in this alpha; use the USB installer
  for this first 0.5.x testing path.

## Validation
- Built both PlatformIO environments successfully.
