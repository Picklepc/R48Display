# R48Display v0.5.0a19 — alpha (arduino-esp32 3.1)

**Pre-release for hardware testing** — install over **USB**.

Rolls up the a16–a18 feature work (boot audio intro, additional display-panel
support) with two fixes.

## Boot audio plays right after boot
The startup chime no longer waits for WiFi (STA) and BLE to connect before
playing — it now plays as soon as the device has finished booting and the display
is up. (The chime task drives its own I2S output, so it's safe this early.)

## Prompt power-off on external-power loss restored
Cutting external power (mower/adapter) again shuts the device down within a few
seconds instead of running for minutes on the onboard battery. Power loss is now
detected by the sharp pack-voltage drop — which fires for *any* supply — in
addition to the existing USB SOF/CDC paths (computer only). It's debounced ~8 s
and still skipped when power-save / battery-backup is enabled.

## Also in this build (a16–a18)
- Onboard speaker with a configurable boot intro melody (startup chime).
- Additional display-panel init modes for broader hardware support.
