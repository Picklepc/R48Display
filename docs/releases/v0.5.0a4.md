# R48Display v0.5.0a4 — alpha (setup AP access recovery)

**Pre-release for hardware testing.** Install over **USB** from the web
installer. If the installer asks about erasing, leave **Erase device** unchecked
unless you intentionally want a factory reset.

## Setup AP recovery
- Makes the temporary setup AP an **open network** for this alpha, removing the
  Windows/Android password-association failure path.
- Forces setup AP channel 1 and `192.168.4.1/24`, so captive portal/DHCP behavior
  is explicit instead of relying on framework defaults.
- Keeps captive DNS and unknown-URL redirects to `http://192.168.4.1/`.
- Pauses BLE/BMS polling while setup AP mode is active, giving Wi-Fi association,
  DHCP, DNS, and the setup page the radio/main-loop priority.
- If saved Wi-Fi credentials exist but cannot connect, setup AP fallback now
  starts after about 30 seconds instead of 90 seconds.
- LVGL status now shows that the setup AP is open and still rotates the setup IP
  hint on-screen.

## Installer data preservation
- Carries v0.5.0a3's installer fix: ESP Web Tools prompts before erase.
- Leave `Erase device` unchecked to preserve saved settings, BMS setup, hours,
  pay records, and maintenance data in NVS.

## Validation
- Built both PlatformIO environments successfully.
