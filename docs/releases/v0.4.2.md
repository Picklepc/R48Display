# R48Display v0.4.2

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Maintenance page no longer wedges the web server
- Opening the Maintenance page fired a burst of simultaneous requests (status, maintenance list, pay, heatmap, plus one history request per maintenance item). That could exhaust the single-threaded web server's connections and leave the web UI unresponsive until a power cycle — while the LCD kept running.
- Page-load requests are now issued one at a time, and the heatmap reuses the already-loaded maintenance list instead of re-fetching it.
- If your device is currently unresponsive: power-cycle it, then update.

## Hour counting: visible and stale-proof
- `/api/status → hours` now reports `counting` and `pause_reason`, so a short day total is diagnosable instead of silent. Counting pauses (by design) when: no BMS reading has arrived yet, the board battery is below its threshold, or the BMS data is stale after a Bluetooth drop — and now it tells you which.
- State hours (standby/active/working) no longer accumulate from a stale frozen reading after a mid-mow Bluetooth drop — previously the last state could keep counting for hours. Total hours still count whenever the pack is known.
- Clock-sanity guard: daily activity records can no longer be written under a bogus year if the clock is wrong at boot.

## Version pickers everywhere
- **Web installer** (https://picklepc.github.io/R48Display/): new version dropdown — flash any release from v0.3.6 up over USB, not just the latest.
- **Settings → Firmware Update**: the on-device picker now lists v0.3.6+ releases.
