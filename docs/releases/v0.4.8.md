# R48Display v0.4.8

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Lower live web overhead (static-until-refresh)
- The dashboard's recurring poll now uses a new compact **`/api/live`** endpoint that omits the heavy, rarely-changing objects — theme, usage, and the duplicate `mower` block — that the config/details table only needs once.
- The full `/api/status` is fetched **once per page load**; the details/config table then stays static until you refresh the page, as intended.
- Combined with the 2.5 s → 5 s poll slowdown in 0.4.6, this substantially cuts the JSON the ESP32 builds and serializes on every poll while a browser tab is open — the recurring workload behind the web-stability issues.

## Groundwork
- Logged the arduino-esp32 3.x migration plan (milestone 0.5.x in `TASKS.md`) — the path to making on-device GitHub update checks work, via the 3.x-only `setBufferSizes()` to shrink the TLS buffers.
