# R48Display v0.5.0a21 — alpha (arduino-esp32 3.1)

**Pre-release for hardware testing.** Install over **USB** (or over-the-air from
a20+, which pauses BLE during the transfer so it doesn't drop).

## Full backup & restore — migrate to a replacement board
**Settings → Backup & Restore.** A backup is a byte-for-byte image of the device's
storage (the NVS partition): every setting, the **complete hours history**,
maintenance, and pay records. Restore it onto a freshly-flashed board and it comes
up as an exact clone — so when a board fails, you keep all your history.

- **The backup file contains your Wi-Fi/MQTT passwords in plain text.** The UI
  warns about this; keep the file private.
- Restore overwrites everything and reboots. A bad or partial restore just resets
  NVS to defaults on the next boot — it can't brick the board.

## Hours & pay numbers reconciled
The different views disagreed; they now line up:

- The **hours CSV** reported "driving" as the active total (double-counting
  mowing) and omitted the current day. It now reports `driving = active − mowing`
  and includes today — matching the on-screen annual chart.
- The **Pay** page showed `0.0 h` next to a non-zero earned amount. Hours now show
  2 decimals so they match the dollars, and the **Pay CSV** exports the
  in-progress period instead of a blank row.
- Note: some *historical* pay-vs-meter mowing totals still differ, because
  timestamped work sessions were lost to clock/reboot gaps during earlier
  instability. That's past data and can't be recovered, but new activity now
  tracks together.

## Safer updates
- App-only updates are refused across the **0.4.x ↔ 0.5.x bootloader boundary**
  (they wouldn't boot) and point you to the USB installer; the manual-upload page
  warns about it too.

Carries a20's reliable-OTA fix and everything prior.
