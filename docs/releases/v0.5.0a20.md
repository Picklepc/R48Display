# R48Display v0.5.0a20 — alpha (arduino-esp32 3.1)

**Pre-release for hardware testing.** Install this one over **USB** — the fix it
carries only helps *future* over-the-air updates (see below).

## Reliable over-the-air updates (pause BLE during OTA)
On a live, BMS-connected device, an over-the-air update (ArduinoOTA / PlatformIO
espota) shared the radio and internal RAM with the active BLE connection, so the
transfer stalled and dropped mid-upload (`WinError 10054`, seen around 50–70%). The
OTA path now **tears BLE down at the start of the transfer** — the same teardown
the on-device updater uses — and brings it back if the upload fails.

Because this fix lives in the *receiving* firmware, it only takes effect for
updates **after** a20 is installed. Flash a20 over USB once; subsequent
a20 → a21 (etc.) over-the-air updates should then complete cleanly.

Everything from a19 (boot audio at boot, prompt power-off, and the a16–a18
audio/display work) is included.
