# R48Display v0.4.0

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Update safety & recovery
- **Automatic rollback.** A firmware image that fails to boot no longer bricks the device — the bootloader reverts to the previously working version. The new firmware only becomes permanent once it has booted far enough to be confirmed healthy.
- **Wrong-file guard.** The manual updater now rejects anything that isn't an app image, so uploading `firmware-merged.bin` (the USB-only file) by mistake is blocked with a clear message instead of hanging the device. The manual-upload help now spells out that `firmware.bin` is the file to use.

## Install any version (reinstall / roll back)
- **Settings → Firmware Update** now has a **version picker**: choose any published release and install it — including reinstalling the current version or rolling back to an earlier one. This is the easy way to step back if a new build misbehaves, without needing a computer.
- The one-click **Install** for the latest release still works as before.

## Notes
- Rollback protects against a firmware image that can't boot. For a bad file caught *before* flashing, the wrong-file guard and the version picker are the first line of defense.
- If a device ever can't boot at all, USB recovery via the web installer (**https://picklepc.github.io/R48Display/**) always works.
