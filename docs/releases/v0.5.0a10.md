# v0.5.0a10

Alpha pre-release for arduino-esp32 3.x Wi-Fi/BLE recovery testing.

## Changes

- Delays BLE startup until STA has held an IP for 45 seconds, so Wi-Fi and the web
  server come up before NimBLE allocates/controller work begins.
- Removes the early boot `NimBLEDevice::init()` before `WiFi.begin()`.
- Switches automatic and settings-page BLE discovery to passive scanning to avoid
  active scan-response traffic under Wi-Fi coexistence.
- Lets the settings-page manual BLE scan cancel an automatic scan already in
  progress instead of returning only `scanning`.
- Stops immediate NimBLE reset after a scan timeout. Repeated scan timeouts now
  pause BLE for 5 minutes while leaving Wi-Fi/web/LVGL alive.

## Testing Notes

- After boot, the web UI should be reachable before BLE begins scanning.
- LVGL BLE status should show a waiting/ready state first, then scan less
  frequently.
- If the BMS still is not listed, capture `/api/status` after the web UI comes up
  and one `/api/ble/scan` response.
