# R48Display v0.4.1

**OTA from v0.3.0 or later is safe** — the partition table is unchanged.

## Fix: "Could not reach GitHub" on update check
- The on-device update check (and the version picker that lists releases from it) could fail on a memory-tight device because the secure connection to GitHub competes with Bluetooth for RAM.
- The check now retries with Bluetooth briefly torn down to free heap for the TLS handshake — the same mitigation the install path already uses — then restores Bluetooth. Normal checks are unaffected; only a failed attempt triggers the fallback.

The **version picker** (Settings → Firmware Update) added in v0.4.0 lists recent releases from that check, so this also unblocks selecting and rolling back to a specific version from the web page.
