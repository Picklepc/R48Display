# v0.5.0a9

Alpha pre-release for arduino-esp32 3.x Wi-Fi/BLE coexistence testing.

## Changes

- Keeps the v0.5.0a8 automatic BMS discovery changes: callback-driven scans,
  scan timeout recovery, lower-duty scan parameters, and earlier STA-mode NimBLE
  initialization.
- Changes the settings-page manual BLE scan endpoint to use non-blocking
  `NimBLEScan::start()` plus an explicit timeout instead of
  `NimBLEScan::getResults(duration)`, so a lost NimBLE scan-complete event cannot
  park the web server handler indefinitely.
- Returns a JSON error if the manual BLE scan cannot start or if the controller
  fails to finish before the guard timeout.

## Testing Notes

- Expected serial logs:
  - `[BLE] init: internal heap before -> after`
  - `[BLE] BMS scan end: seen=N, match=yes/no, reason=..., heap=...`
  - `[BLE] web scan: N seen (internal heap H)`
  - `[BLE] BMS scan timeout ...` only if the controller wedges.
- If `seen=0` persists with a known nearby BMS, capture the serial log from boot
  through the first automatic scan and one settings-page manual scan.
