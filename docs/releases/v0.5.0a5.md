# v0.5.0a5

Alpha pre-release for setup Wi-Fi connection testing on the arduino-esp32 3.x
core.

## Changes

- Removes the explicit `WiFi.softAPConfig(192.168.4.1, ...)` call from setup
  mode and uses the Arduino-ESP32 default SoftAP address instead.
- Restarts Wi-Fi through `WIFI_OFF` before starting the setup AP, avoiding the
  S3/S2 start-stop-start path that can leave the AP invisible or unreachable.
- Fully deinitializes BLE while the setup AP is active, and blocks manual BLE
  scans from the setup web UI so BLE cannot grab radio resources during Wi-Fi
  provisioning.
- Applies reduced setup-AP transmit power after the AP has started, matching the
  ESP32-S3 forum workaround for boards that advertise but refuse client
  association at full power.
- Runs Wi-Fi network scans from setup mode as `WIFI_AP_STA`, so the settings
  page can scan nearby routers without intentionally tearing down the setup AP.

## Testing Notes

- Connect to the setup network shown on the LVGL screen.
- The setup network is open/no-password when possible.
- Browse to `http://192.168.4.1/` if the captive portal does not open
  automatically.
